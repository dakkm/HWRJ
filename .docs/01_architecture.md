# Architecture

文档版本：v0.2  
最后更新：2026-09-11

本文档只记录当前已经确认的模块、职责和数据流。

---

## 1. 总体结构

```text
用户
  ↓
GUI 业务语义层
  ├─ 任务设置
  ├─ 目标参数
  ├─ 场景与运动
  ├─ 环境与观测
  └─ 计算与输出
  ↓
GUI 数据映射层
  ↓
forward-request-v1
  ↓
统一进程执行层
  ↓
01 / 02 / 03 / 04 标准入口
  ↓
coreprogram
  ↓
runs/run_*
  ↓
GUI 结果解析层
  ↓
曲线 / 点图像 / 表格 / 结果摘要
```

核心原则：

```text
GUI 层使用用户语言；
接口层使用程序语言。
```

## 3. GUI 业务层级

### 3.1 任务设置

用于定义一次任务最基础的信息。

建议包括：

```text
任务名称
仿真时长
目标数量
任务说明
任务文件的新建 / 打开 / 保存 / 另存为
```

### 3.2 目标参数

用于定义目标自身的几何、热物性和辐射特性。

建议组织：

```text
目标组成
尺寸与质量相关参数
热物性
初始温度
内部热源
红外发射率
太阳吸收率
当前源码实际支持的其他目标参数
```

多目标优先支持：

```text
统一参数
→ 必要时再展开单目标独立设置
```

### 3.3 场景与运动

用于定义群体与单目标的空间状态。

建议包括：

```text
目标群初始状态
目标群速度
目标群角运动
单目标位置
单目标速度
单目标释放时间
单目标激活状态
```

### 3.4 环境与观测

环境部分只显示当前正向程序实际支持的参数。

当前不加入：

```text
地球红外
对流换热边界
环境流体温度
```

观测部分根据当前后端支持项组织，例如：

```text
观测位置
观测方向
参考上方向
跟踪目标
孔径尺寸
焦距
像面尺寸
观测系统运动参数
```

### 3.5 计算与输出

根据当前功能模块动态显示。

示例：

```text
正向仿真：
- 运行模式
- 超时时间
- 输出选项

智能预测：
- temperature
- point-image
- both

相似度评估：
- 参考 run
- 候选 run
- features / similarity

红外场景构建：
- 相似度要求
- 候选数量
- 搜索设置
```

## 4. GUI 到后端的内部映射

该映射只存在于程序内部。

```text
GUI“任务设置”
    ↓
CASE 等相关字段

GUI“目标参数”
    ↓
TARGET_PHYSICS 等相关字段

GUI“场景与运动”
    ↓
GROUP_STATE
TARGET_SCENE

GUI“环境与观测”
    ↓
ENVIRONMENT
OBSERVATION

GUI“计算与输出”
    ↓
模块运行参数 + 输出选项
```

重要：

```text
一个 GUI 页面可以映射多个后端分区；
一个后端分区也可以由多个 GUI 控件共同生成。
```

因此不能机械地把后端 JSON 分区一一做成 GUI Tab。

---

## 5. 当前主链路

```text
新建/读取任务
→ GUI 业务语义层编辑
→ 映射生成 forward-request-v1
→ 任务校验
→ 选择功能模块
→ 启动标准入口
→ 捕获 stdout/stderr
→ 解析 GUI_PROGRESS
→ 后端生成 run
→ GUI 读取规范输出
→ 结果显示
→ 记录历史任务
```

## 6. 模块边界

不要修改：

- `coreprogram` 冻结算法；
- 模型文件；
- Fortran 程序；
- `forward-request-v1` 数据合同；
- 正式输出合同。

不允许：

- 把旧流程图中后端已取消的参数重新加回 GUI；
- 为了界面方便私自改变后端合同；
- 用程序字段名替代用户业务语言作为主导航。

允许新增：

- MFC GUI 类；
- 业务任务数据模型；
- 任务映射类；
- JSON 解析类；
- `ProcessManager`；
- `ResultLoader`；
- 可视化控件；
- 历史任务管理。
