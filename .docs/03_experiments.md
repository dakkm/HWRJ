## EXP-20260911-ui-information-architecture

### 1. 实验目的

重新审视 GUI 参数层级，避免将程序内部数据分类直接暴露给用户。

### 2. 输入依据

```text
当前总体设计流程图：只作为业务流程参考
当前 v1.0.0 后端源码：作为真实参数能力依据
当前 forward-request-v1：作为内部数据合同
```

### 3. 发现

- 旧流程图中的部分内容已过时；
- 当前正向仿真不包含地球红外边界；
- 当前正向仿真不包含对流换热边界；
- 程序六分区结构不适合作为用户一级导航；
- 用户更适合按照任务设计逻辑逐级输入。

### 4. 新的 GUI 一级层级

```text
① 任务设置
② 目标参数
③ 场景与运动
④ 环境与观测
⑤ 计算与输出
```

### 5. 结果判断

```text
Accepted：
采用业务语义层级作为 GUI 信息架构，
内部通过映射层生成 forward-request-v1。
```

### 6. 后续动作

- 更新 architecture；
- 更新 decisions；
- 修改下一条 Codex Prompt；
- P2 按新层级实现任务编辑器。
