# Project Brief

文档版本：v0.2
最后更新：2026-09-11
当前阶段：MFC GUI 重构阶段
当前主问题：现有 GUI 已有四模块入口，但尚未形成统一任务设计、运行监控和结果可视化工作区。
当前下一步：实现面向用户业务认知的场景任务编辑器，内部映射到 `forward-request-v1`。

---

## 1. 项目目标

构建面向红外场景正向仿真、智能预测、相似度评估和红外场景构建的一体化 GUI。

GUI 一级业务层级：

```text
① 任务设置
② 目标参数
③ 场景与运动
④ 环境与观测
⑤ 计算与输出
```

后端统一数据合同：

```text
forward-request-v1
```

注意：

```text
forward-request-v1 是内部数据合同，不直接等同于 GUI 页面层级。
```

当前目标不包括：

- 修改冻结后端；
- 修改模型和 Fortran；
- 修改正式数据合同；
- 将旧流程图中的过时参数恢复到 GUI；
- 加入当前源码未支持的地球红外、对流边界等输入。

## 3. 当前关键结论

- `coreprogram` 视为冻结后端。
- GUI 使用用户语言，接口层使用程序语言。
- `forward-request-v1` 是内部合同，不作为 GUI 一级导航。
- GUI 参数必须以当前源码实际支持为准。
- 旧总体设计图只用于参考流程，不作为参数真值源。
- 01、02、04 共享同一完整任务。
- 03 以 run 为输入。
- 当前未实现的地球红外、对流换热等参数不得出现在 GUI 中。

---

## 4. 当前允许修改范围
