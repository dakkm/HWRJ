## ISSUE-006：旧总体设计图与当前源码存在参数差异

状态：Open  
严重程度：Medium

### 现象

旧总体设计图包含当前正向程序已经不再支持或未实现的内容。

当前已确认示例：

```text
地球红外
对流换热边界
```

### 风险

若直接按旧图设计 GUI，会出现“界面可输入但后端不处理”的假功能。

### 临时处理

```text
所有 GUI 参数必须先核对当前源码和正式数据合同。
```

### 完成条件

- [ ] 当前 GUI 参数清单与正式源码逐项核对；
- [ ] 无无效输入项；
- [ ] 旧文档中过时参数有明确标记或修订。
